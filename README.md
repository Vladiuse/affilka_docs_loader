# Affilka Docs

Скачивает закрытую документацию Affilka (wiki.affilka.net) и превращает её в базу знаний для проекта в Claude.

## Зачем это нужно

Документация Affilka лежит на закрытой вики, которая доступна только после входа. Нейросеть туда попасть не может, поэтому про Affilka она знает только общие вещи и легко выдумывает поля и эндпоинты.

Поэтому мы:

1. Скачиваем всю вики целиком.
2. Переводим HTML в Markdown. От страницы остаётся только текст статьи, без меню, сайдбаров и вёрстки, поэтому файлы получаются в разы меньше по количеству символов. Так в проект влезает больше документации, и Claude меньше отвлекается на мусор.
3. Создаём в Claude проект и загружаем в него эти файлы.

После этого документацию можно не только читать, но и задавать Claude вопросы по ней: как работает функция, где настраивается то или иное, какие параметры у эндпоинта. Claude отвечает по самой документации, а не по общим знаниям.

## Подготовка

Нужны Python и Google Chrome. Драйвер для Chrome Selenium скачает сам.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

## 1. Получить cookie `jwt`

Скрипт заходит на вики под вашим аккаунтом. Для этого ему нужна cookie `jwt` из браузера, в котором вы уже вошли.

1. Откройте https://wiki.affilka.net и войдите в аккаунт.
2. Откройте DevTools (`F12`) → вкладка **Application** → **Cookies** → `https://wiki.affilka.net`.
3. Найдите cookie `jwt` и скопируйте её **Value** целиком. Это длинная строка, около 700 символов.

## 2. Указать cookie в `.env`

Вставьте значение в `.env`:

```
COOKIE_VALUE=eyJhbGciOi...
```

Токен со временем истекает. Если скрипт сохраняет вместо статей страницу логина, возьмите свежий `jwt` и повторите.

## 3. Скачать сайт

```bash
python download_site.py
```

Откроется Chrome. Скрипт начинает с `/en/home` и переходит по всем ссылкам внутри вики. HTML каждой страницы сохраняется в `site/` с той же структурой папок, что и в адресах страниц.

## 4. Перевести в Markdown

```bash
python extract.py
```

Скрипт берёт каждую страницу из `site/`, вырезает блок статьи и сохраняет его как `.md` в `text/`. Имя файла повторяет путь страницы, где `/` заменён на `__`. Например, страница `wiki.affilka.net/en/home/operator-interface-manual` превращается в файл `en__home__operator-interface-manual.md`.

В конце скрипт выводит статистику: сколько файлов сконвертировано, сколько пропущено и сколько символов было в HTML и стало в Markdown.

Если вы обновляете документацию повторно, перед запуском удалите старые `site/` и `text/`. Иначе в них останутся страницы, которых на вики уже нет.

## 5. Создать проект в Claude

1. Откройте https://claude.ai → **Projects** → **Create project**.
2. В **Project instructions** вставьте содержимое файла `project-instructions.md`. Там описано, что это за файлы, как устроены их имена и как отвечать на вопросы.
3. В **Project knowledge** загрузите:
   - все `.md` из `text/`;
   - OpenAPI-схемы из `api_docs/` (`.json`).
4. Задавайте вопросы в чатах внутри этого проекта.

Если документация обновилась, повторите шаги 3–5 и замените файлы в проекте.
