In this section you may see a list of payment methods that relate to affiliate cashouts via crypto wallets and require mandatory verification by the operator. In order to manage the verification of partner payment methods you need to have either SuperOperator access or a role with "Payment Methods Verification" permission enabled.

**PLEASE NOTE!** If the payment method is not verified, the affiliate will not be able to withdraw funds.

**IMPORTANT! **Only “Crypto” payment method is required for verification, other payment methods like “Bank transfer”, “Neteller”, “Skrill”, “PIX”, “Other”, etc. will be verified automatically. This option is implemented to ensure the safe withdrawal of funds, so the operator needs to make sure that the crypto wallets actually belong to the affiliates, and only after that the payment details can be verified. 

__The page contains the following info:__

- **ID**
- **Partner**
- **Payment system**
- **Payment details**
- **Created at**(date and time when payment method was added by affiliate)
- **Status**(unverified, verified, rejected)

You can also **filter and find** payment methods by:

- **Payment Method IDs:**the filter supports multiple values, so you can type several IDs here separated by a comma, “Space” or “Enter” key, the filter will find all methods with the indicated IDs.
- **Partner IDs:**the filter supports multiple values, so you can type several IDs here separated by a comma, “Space” or “Enter” key, the filter will find all affiliates with the indicated IDs.
- **Payment systems:**the filter supports multiple values and autosuggest feature, so you can start typing the name of the payment system and it will appear in the dropdown selector. You can choose several payment systems and the filter will find all of them.
- **Created at:**the filter allows to indicate date ranges (from…to) when the method was created.

You can view a detailed payment method page by clicking on the ID. From here you can verify or reject the payment method of the affiliate.

On a detailed payment method page you will see the method ID, the Partner who added the payment details, when it was requested, payment system, status and cashout data.

Before verifying,** please double-check** whether these payment details really belong to this affiliate. If you have confirmed this with affiliate, you need to click on “Verify”, so that the affiliate can request a cashout. If you are not sure that the crypto wallet details belong to the affiliate, we strongly recommend you to reject the verification of the payment method in order to secure the cashout process.
