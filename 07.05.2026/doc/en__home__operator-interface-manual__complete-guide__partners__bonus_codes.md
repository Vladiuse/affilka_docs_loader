**What is a Bonus Code? **A bonus code is the code that partners will give to their players which will tie players to these affiliates when they enter the bonus code at registration in your iGaming brand. This feature can be used when for some reason affiliates cannot use referral links to promote your brand but can only refer players via bonus codes. In return it is expected that a player will receive a registration bonus in your iGaming brand.

**Approximate user flow:**

- *iGaming brand manager configures some*- **registration-tied**bonus(es) on the iGaming website
- *iGaming operator/affiliate manager assigns some bonus code(s) to a partner in the Affiliate System*
- *partner gives bonus code to players*
- *players register in the iGaming brand with this bonus code*
- *iGaming website issues a bonus by bonus code to player and makes a request to Affiliate System with the bonus code to receive an stag (unique affiliate identifier)*
- *if this bonus code exists in the affiliate system, the player is tied to partner via this id*

To find the bonus codes in the Operator Interface, click "Partners" and choose "Bonus codes" tab in the navigation menu. Or use the direct link **/casino/bonus_codes** . On this page you will be able to view, filter and find all active and archived bonus codes as well as create a new one. By clicking on the players count, you will be redirected to the **/casino/players** page filtered by this bonus code.

To create and assign a new bonus code, click **"**New**"** in the top right corner of the screen. Fill in the required fields: choose the brand where the bonus code will be active, add affiliate's unique identifier, fill in affiliate's promo-code (this is the alphanumeric code you can see in their referral links) – the bonus will be attached to a specific promo created by affiliate, fill in the Bonus Code (e.g. XMAS2020), add a description and press "Submit".

**Note!** BONUS25 and bonus25 are different bonus codes for the system.
