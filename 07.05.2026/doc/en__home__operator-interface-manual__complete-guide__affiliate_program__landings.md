A landing page is a specific URL or path on a website (e.g., `https://casinosite.com/christmas_bonus`) that serves as the destination for referral links shared by affiliates. Landing pages are always hosted under a landing domain (e.g., `https://casinosite.com`). While the landing domain identifies the overall site, the landing page represents a specific path within that domain. Please, note that when a landing domain is added, a landing page is automatically created for that domain, which usually equals the website’s homepage.

This page contains a list of all landing pages within your affiliate program to which affiliates can send their traffic.

The list of landings is divided into 2 tabs: active and archived.

- **Active**: contains all active landings that are visible to your partners during a promo or campaign creation/editing.
- **Archived**: contains all archived landings that are no longer available to your partners when they create or edit their promos and campaigns.

You can filter the landings by:

- **Name**. It's a name assigned to a landing. It's a text input field that supports partial search.
- **Brand**. It's a brand to which the landing is connected and to which the end-users will be referred. Please, note, that sub affiliate landings are not connected to any brands but to the whole affiliate program. The filter supports multiple values and an autosuggest feature. You can select several brands from the drop-down selector and filter the landings by them.
- **State**. Represents one of the 3 landing's states: personal, dedicated, shared. The filter supports multiple values and an auto-suggest feature. You can select several states from the drop-down selector and filter the landings by them.
- **Subaffiliate (All/Yes/No):**If a landing page is designed to be used in subaffiliate campaigns and attract subaffiliates, choose “Yes”. If the landing page isn't designed for subaffiliates but for players, choose “No”.
- **Default**- **(All/Yes/No):**If a landing page is designed to be used in default affiliate campaigns (e.g. campaigns that are automatically created upon affiliate sign-up), choose “Yes”. If the landing page isn't used in default campaigns, choose “No”.
- **Country**: a specific country for which the landing is designed. The filter supports multiple values.
- **Language:**the language used in the landing page. The filter supports multiple values.
- **Tags:**any custom tags that you've labelled your landing pages with. The filter supports multiple values.
- **URL**. The URL of the landing. It's a text input field that supports partial search.

In addition to this, in the list of Landings you can also see the following info:

- **The Landing Preview:**an image you upload for this landing page as a preview of the webpage;
- **Name**: a name assigned to a landing.
- **Brand**: a Brand to which the landing is connected and to which the end-users will be referred. Please, note, that sub affiliate landings are not connected to any brands but to the whole affiliate program.
- **Campaigns count:**represents the count of campaigns that have been created for a specific landing page. By clicking on the Campaigns count you will be redirected to the “Campaigns” page and it will be filtered by the ID of the specified landing page.
- **Promos count:**represents the count of promos that have been created for a specific landing page. By clicking on the Promos count you will be redirected to the “Promos” page and it will be filtered by the ID of the specified landing page.
- **Country**: a specific country for which the landing is designed.
- **Language**: the language used in the landing page.
- **Created at:**the date when the Landing was created in the Affiliate Program.
- **Tags**: any custom tags that you've labelled your landing pages with.

to create a landing, press “New”. Fill in the form:

1) **Name -**  Add the name of your landing (e.g. “Running Tournament”).

2) **Subaffiliate checkbox** - If this landing is designed to be used in subaffiliate campaigns and attract subaffiliates to your affiliate program, tick off the checkbox “Subaffiliate”. If the landing is designed to attract players to your iGaming brand, leave this setting empty.

3) **Brand** - Choose the brand the landing is created for. This setting cannot be used with “Subaffiliate” landings. Subaffiliate landings are created in the context of the whole affiliate program, not a brand.

4) **Domain** - Choosethe domain URLwhere landing will be located (=base/root domain url), e.g. `https://casinosite.com`. If you want to add more domains please use the “Landing domains” page.

5) **Path** - Add a path to the specified domain (e.g. `/tournaments/running`).

6) **State -** Choose the state of the landing (personal, dedicated, or shared). Depending on the chosen state, it will be visible either to all affiliates or only to those to whom this landing is assigned individually.

7) **Country -**  Indicate the country for which the landing is created.

8) **Language -** Choose a language that is used in the landing.

9) **Tags -** If applicable, indicate a custom tag that will help you easily find the landings of the same category in future. 

10) **Priority landings checkbox** - If you want this landing to be reflected on top of other landings in the Affiliate Interface, tick off the checkbox “Priority”.

11) **Default checkbox - **If you want this landing to be used in default affiliate campaigns (those that are automatically created upon affiliate registration), tick off the checkbox “Default”.

12) **Image** - If needed, upload the preview image of your landing page in the Imagesection.

- **Personal**– visible only to specific affiliates. You can assign a personal state to the Affiliate program domain, thus offering the sub-affiliate program deals to selected partners only.
- **Shared**– visible to all affiliates.
- **Dedicated**– visible to specific Operators. Only Operators without any "Landings" permissions can be assigned Dedicated Landings otherwise all landings in all states will be available to them.

You can prioritise the desired landing page and place it above all other landing pages in the Affiliate Interface.

To prioritise a landing, you need to activate the "Priority landing" checkbox on the chosen landing page and press the “Submit” button to apply the settings. Keep in mind that the "Priority landing" setting can be applied only for landings with "Shared" state. You will find this setting at the bottom of all settings when creating new landings or editing existing ones.

As soon as you apply the priority setting to the landing, it will be placed above all other "Shared" landings in the Affiliate Interface during a campaign/promo creation.

If a partner has “Personal” or “Dedicated” landing pages, these landings will be given a higher priority, than the "Shared" landing pages.

So the priority funnel during campaign/promo creation is:

1) Personal or Dedicated landings

2) Shared landings with the Priority flag

3) Shared landings without the Priority flag.

Landing pages within the same priority group are sorted by the date of their creation.

There is no limit for landing pages with the "Priority landing" setting applied, but we recommend that you have no more than 2-3 of those within one brand.

You can control which landing pages will be used with default affiliate campaigns – those that are created automatically with default commissions when an affiliate registers.

To make a landing “Default”, you need to activate the "Default landing" checkbox on the chosen landing page and press the “Submit” button to apply the settings.

Keep in mind:

- the "Default landing" checkbox can be activated only if this landing page is in "Shared" state.
- Only 1 landing page can be in "Default" status per brand at a time. Setting a new landing as default will automatically removethe "Default" status from the previously assigned one.

You can also remove the "Default" status entirely by unchecking the box on all landings for a brand. In this case, default campaigns will no longer be created for that brand when new affiliates sign up.

to archive a landing, press “Archive” next to the landing in the list of landings. The date when the landing is archived will be logged and displayed in the “Archived” landings tab under the “Archived at” column.

The “Archived” state means that the landing cannot be edited, is not available for new campaigns and is not visible to new affiliates. Nonetheless, it remains active for the old campaigns.

to edit a landing, press “Edit” next to the landing in the list of landings.

You can change all fields (name, domain url, path, preview, state, priority flag). After you edit the landing, it will be automatically changed in all affiliate promos. If affiliates used these landings, their players will be directed to the newly edited page instead of the old one.

You can also edit landings that were archived.
