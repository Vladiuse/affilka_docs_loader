Understanding and analysing traffic by source is an integral part of working in affiliate marketing. Therefore, in the first version we've added the ability to specify the traffic source in the affiliate interface when creating a campaign/promo.

During the campaign/promo creation when choosing a landing affiliates need to specify one of 30+ traffic sources using "Choose traffic source for promo" field**. **Affiliates can use a search bar to easily find the source they need.

This field is not mandatory and it can be filled later by pressing promo's "Edit" button on the campaign's detailed page in the Promos section.**Please note** if the traffic source is specified on a promo it won't be possible to edit this field anymore. 

Affiliates can find a specified traffic source on:

- "My campaigns" (/partner/campaigns) page under the "Traffic source" column.This filed will reflect traffic sources from all the promos created under the specified campaign.
- Campaign's detailed page (/partner/campaigns/*id*) in the Promos section under the "Traffic source" field.

Affiliates can also filter campaigns using the "Traffic Sources" filter on the "My campaigns" page.

Operators can find a specified traffic source on:

- "Campaigns" (/casino/campaigns) and campaign's detailed pages (/casino/campaigns/*id*) under the "Traffic source" field. This field will reflect traffic sources from all the promos created under the specified campaign.
- "Promos" (/casino/promos) and promo's detailed pages(/casino/promos/*id*) under the "Traffic source" field.
- In the csv exports from the "Campaigns" and "Promos" pages.

Operator can also filter campaigns and promos using the "Traffic Sources" filteron the "Campaigns" and "Promos" pages.

With future releases we plan to implement filters and groupings to the Partner Statistics (/casino/report) to make it easier to analyse all the necessary data in terms of traffic source.

We can now send the info on the traffic source specified in the promo within the referral links while redirecting your players to the target landing page. Thus, you will be able to retrieve this data directly from your brand's landing page.

To enable this feature for your iGaming brand(s), please, contact your Account Manager.

We've added "Registrations", "FTDs count", "Deposits count" columns and "Clicks to Regs", "Clicks to FTDs", "Clicks to Deposits" conversion metrics to make our report even more robust and provide you with valuable insights about your traffic.

- "Registrations" - number of player registrations for a specified period.
- "FTDs count" - number of first deposits for a specified period.
- "Deposits count" - number of deposits for a specified period.
- "Clicks to Regs %" - (Registrations/Unique clicks) * 100% for a specified period.
- "Clicks to FTDs %" - (FTDs count/Unique clicks) * 100% for a specified period.
- "Clicks to Deposits %" - (Deposits count/Unique clicks) * 100% for a specified period.

**Please note **that Registrations, FTDs, Deposits presented in the Traffic report relate to clicks that were generated by clicking on a referral link. It means that players (and their deposits) that were imported using bonus codes or data migration won't be presented in the Traffic report. 

To make it easier to identify the requested report among others on the "Requested reports" (/casino/requested_reports) page we've implement the ability to assign names to reports at the time of export. This is how it works:

- Go to the "Partner Statistics" page and export report via CSV.
- Under the "Specify requested report's name" pop-up you need to specify name for your requested report by filling the "Name" field. If you request your "Favourite" report, the "Name" field will be pre-filled with the report favourite name.
 This field is not mandatory and can be filled later on the requested report page.
- Press on the "Submit" button to save the name and request the report.
 Please note that if you press on the "Cancel" button, the report won't be exported.

Operators can find and edit the requested report's name on the "Requested reports" and requested report's detailed pages under "Name" field. To edit name press the "Edit" button and fill in the desired name.
