This report allows you to view and analyse the performance of all of the subaffiliates within your Affiliate Program. You can filter the report by specific date range, Parent Affiliate, Subaffiliate Subaffiliate commission strategy, campaign, promo, etc.

You can choose what columns you'd like to see in the report and reorganize them in the order that suits you by dragging and dropping the column names.

You can also view performance report in one single currency – EUR (or another base fiat currency if it's different from EUR). To do that, tick off the checkbox "Convert all currencies to EUR" in the filters block. By default, today's exchange rates are applied. If you want some other date, indicate the required Exchange rates date in the Filter above.

You can get the report in CSV/XLSX/XML/JSON formats by clicking on the corresponding button at the top of your statistics table.


By default, when you first load the Subaffiliate report, you will see the data in the following format:

- The report shows Parent Affiliate, Subaffiliate and Subaffiliate level for the current calendar month;
- The current date is used for the exchange rates which are used to calculate total values.

**PLEASE NOTE!  **The operator is able to view the partner connections if they are Dedicated operator to both Parent affiliate and Subaffiliate.


- **Date range**– indicate the time period you’d like to analyze here. E.g. 3 months, from September 1, 2025 to November 30, 2025.
- **Parent Affiliate IDs**- (full match mode, supports multiple values separated by a comma, “Space” or “Enter” key) – indicate unique IDs of those Parent affiliates you want to analyze.- *If the operator is a dedicated operator to Parent Affiliate and all Subaffiliates, they will see all partner connections within all Subaffiliate levels when filtering by Parent Affiliate IDs.*

**Superoperators see all partner connections by default.**

- **Subaffiliate IDs**- (full match mode, supports multiple values separated by a comma, “Space” or “Enter” key) – indicate unique IDs of those Subaffiliates you want to analyze.
- **Subaffiliate Level -**indicate a level of Subaffiliates you would like to filter the report with
- **Subaffiliate Campaign IDs**- (full match mode, supports multiple values separated by a comma, “Space” or “Enter” key) – indicate unique IDs of those Subaffiliate campaigns you want to analyze.
- **Subaffiliate Promo IDs**- (full match mode, supports multiple values separated by a comma, “Space” or “Enter” key) – indicate unique IDs of those Subaffiliate promos you want to analyze.
- **Subaffiliate Promo Codes**-(full match mode, supports multiple values separated by a comma, “Space” or “Enter” key) – indicate unique promo codes of those Subaffiliate promos you want to analyze.
- **Subaffiliate Strategies**- (dropdown selector with autosuggest feature; supports multiple values) – choose or type Subaffiliate commission strategies you want to analyze.
- **Brands**- choose one or several iGaming brands from the dropdown selector. If a brand is not specified, you will see cumulative statistics on all of your brands taken together.

- **Registrations count**– the number of player registrations via Subaffiliate campaigns
- **First deposits count and First deposits sum**- number of FTDs and their sum
- **Deposits count and Deposits sum**- number of overall deposits (including first deposits) and their sum
- **Subaffiliate Casino NGR**- Net Gaming Revenue generated by casino players invited by Subaffiliates.- *If in your affiliate program Admin Fee is deducted from Casino Real NGR, then this formula will be calculated as*- `Casino Bets – Casino Wins – Casino Bonuses – Casino balance corrections – Casino Taxes`- *– Casino Admin fee*
- **Subaffiliate SB NGR**- Net Gaming Revenue generated by sportsbook players invited by Subaffiliates.- *If in your affiliate program Admin Fee is deducted from SB Real NGR, then this formula will be calculated as*- `SB GGR - SB bonuses - SB balance corrections - SB 3rd party fees - SB Admin Fee - SB`- *Taxes*
- **Subaffiliate Poker NGR**- Net Gaming Revenue generated by poker room players invited by Subaffiliates. The formula is calculated as follows:- `Poker Rake Sum - Poker Bonuses Sum - Poker Balance Corrections Sum - Poker 3rd Party Fees Sum`

You can decide how data is presented in the report by breaking it down by brand, Parent Affiliate, Subaffiliate, Subaffiliate level, specific period: year, month, week, day; etc.

If you don't need to break down the data, you can leave the checkboxes empty and you will see the total stats for all Subaffiliates and brands for the selected date range. If, however, you need to see how different Subaffiliates, Parent Affiliates or campaigns pair against each other during specific calendar periods, you can set the corresponding grouping.

*E.g. an affiliate has been promoting your casino via 3 campaigns for less than a year (say, from October 2024 till September 2025). The affiliate brings in fiat traffic. Grouping data by campaign and month will show you the total stats of eaсh campaign broken down per calendar month.*

The following data grouping options are available:

- **Period:**you can break down data by day, week, month or year.- *E.g. if you want to view daily performance of a specific Parent Affiliate throughout the current month, filter the report by the IDs and apply data grouping by Period: Day. Remove the data grouping by Parent affiliate, Subaffiliate and Subaffiliate level because it is unnecessary for the current report. If it is convenient for you, convert all data into the currency of your choice. The report will look similar to this:*


- **Parent affiliate:**break down data by Parent Affiliate. Use these grouping if you want to compare different Parent affiliates with each other.


- **Subaffiliate:**break down data by Subaffiliate and analyze their performance. It works best with Parent affiliate IDs filtering to compare the input of each Subaffiliate within a Parent affiliate


- **Subaffiliate level:**break down data by the level of each Subaffiliate


- **Subaffiliate campaign:**break down data by Subaffiliate campaign. Use it to compare different Subaffiliate campaigns with each other.


- **Subaffiliate promo:**break down data by Subaffiliate promos (referral links). Use it to analyze how each referral link to attract Subaffiliates is pairing against each other.


- **Subaffiliate strategy:**break down data by Subaffiliate commission strategy. Use it if you want to analyze affiliate performance on specific deal.


- **Brand:**break down data by the iGaming brand. Use this grouping if you want to compare different brands with each other.- *E.g. if you want to compare specific Parent affiliate’s performance on 2 different brands during the current year, indicate the required date range, filter the report by Parent affiliate in question, use currency conversion options if needed, apply the data grouping by Brand and remove all other groupings. The report can be extracted in CSV/XLSX as well as in XML/JSON formats via statistic feed links. If the report is too big to display within the interface, the file (or a link to the report download via the interface) will be emailed to the email you’re signed in with.

To get a report in CSV/XLSX format, first, apply the required filters and data groupings and choose the fields you want to see in the report, and press “Filter”. After that, click “Report export” and choose “CSV/XLSX”. As soon as the report is ready, you will be notified via email.

The email will contain an attached XLSX file, in case you want to view the report straight away. The email will also contain a link to the detailed page of the __requested report__ in the Affilka interface where you can download the report via browser. The available download options include Zipped CSV (consisting of 2 files: report rows and report totals) and XLSX (one file divided into 2 tabs with report rows and report totals).

When you want to extract the report in CSV/XLSX formats from the “Subaffiliate report” page, you will be prompted to give a name to your requested report.

If you haven't indicated a name for your report when requesting it or you hit a time-out limit and didn't have a chance to indicate the report name, you can give the name to it __on the detailed requested report page __by clicking the “Edit” button. 

Choose something that reflects the contents of the report so that you could easily navigate among your requested reports once they're ready.

The requested report will have an “subaffiliate report” type assigned to it.

You can extract performance report in XML/JSON. To retrieve the statistics feed link, press "Export report" button and choose the desired format. Every link can be copied and opened outside an active session off site thanks to individual statistic tokens assigned to each operator. The statistic token remains static so that you could fetch data across different months without having to log in.

If an Operator is no longer working with the affiliate program and is removed from the team or their access to the operator interface is compromised, you can always expire the statistic token for this operator email. To block access to the statistic feed for a specific operator email, find __the Settings>Operators tab__ (/casino/users), find the Operator's email, click on their ID and press “expire” next to the statistic token on a detailed Operator page.

**IMPORTANT!** The data fields, data groupings, their order as well as currency representation in the XML/JSON report corresponds to the filters you have configured.
