This page can be reached via the **/casino/brands** link.

It contains all iGaming brands integrated into your Affiliate Program, their IDs, names, URLs, state (enabled/disabled).

If a brand is disabled, it is not visible to affiliates and they cannot create referral links to promote this brand. Only our team can enable/disable a brand.

If you click on the brand name, you’ll see a more detailed brand page. Additional info includes brand description, brand currencies (currencies in which player can deposit and make bets in your iGaming brand), base fiat/cryptocurrencies, brand contacts (may include Email, Phone, Microsoft Teams account, Telegram).

If you want to apply the changes on the detailed brand page, then click on "Name" or on "Edit". You’ll be able to edit the brand name, its description, visit cookie lifespan (days) and brand contact details. 

URL, Currencies, Base currencies can only be changed upon request to the Affilka team. 

You can set an Individual Cookie Lifespan for each brand. Since the default cookie lifespan is set at 30 days for the affiliate program and this means that if the same user clicks 20 times on a referral link within 30 days, in this case 1 click will be counted as unique one, 19 as non-unique.

**To set or change the lifetime of cookie**, click “Edit”, then add the required count of the days in Visit cookie lifespan (days) field and click “Submit”.

**PLEASE, NOTE! **You can use this option not only at the brand level, but also at the promo level, and then the following rule applies: **The individual setting of a more granular level always overrides the setting of a higher level: promo setting overrides brand setting, and brand setting overrides the default affiliate program setting. **

On each brand page, you’ll see a link to the Report for this brand. When you click on "Report", you will be directed to the Partner Statistics page, where a default report on a specific brand with filters, columns and groupings will be applied.
