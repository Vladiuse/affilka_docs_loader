This page can be reached via the **casino/exchange_rates** link.

Here you can find the conversion rates that are applied to the reports and are used in billing calculation.

The page contains from/to currency pairs and exchange rate dates.

You can **filter and find** data by:

- Exchange rates date – allows you to select the required dates;
- Currency pairs – allows you to select from/to currencies, supports multiple values, will autosuggest ready currencies that are available in the brand settings from the drop-down menu.

If you select, for example EUR and USDT, then the page will show you only 1 pair, that is, 1 EUR to USDT exchange rate.

If you select **more than 1 currency in the currency pairs filters**, the page will allow you to find rates per each currency. 

For example, you chose EUR and USD/USDT and ETH. This means that you will be able to find information on EUR/ETH, EUR/USDT, USD/ETH, USD/USDT pairs.
