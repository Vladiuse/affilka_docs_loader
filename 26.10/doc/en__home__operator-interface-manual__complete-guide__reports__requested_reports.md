In this section you may see your own history of report requests in CSV/XLSX formats, you can track report generation progress and you can also download ready reports via browser.

Here you will also find those reports that couldn't be displayed within the interface in case of a time-out limit.

**Please Note! **This tab includes requests for reports on activities from the Partner Statistics section as well as Cohort Analysis export requests. It does not include requests from the Traffic Report page. 

All activity and cohort reports that a user requests in CSV/XLSX format are stored on a "Requested Reports" page under the "Reports" tab in the navigation menu.

The user can only view their own report files, they won't be able to see what other users request.

__The page contains the following info: __

- **ID**
- **Name**(the name you indicated when requesting a CSV/XLSX report export)
- **Parameters**(filters, columns, groupings applied to this report)
- **Actor**(user who requested the report)
- **Type**(activities report or cohort analysis)
- **State**(report generation progress: Successful, Processing, Failed)
- **Requested at**(time the report was requested)
- **Action**(link to download the fully generated report via browser)

By clicking on the request ID, or the report name, you can see the parameters that are included in the report.

When you want to extract the report in CSV/XLSX formats from the “Partner Statistics” page or the “Cohort Analysis” page, you will be prompted to give a name to your requested report.

If you haven't indicated a name for your report when requesting it or you hit a time-out limit and didn't have a chance to indicate the report name, you can give the name to it on the detailed requested report page by clicking the “Edit” button.

Choose something that reflects the contents of the report so that you could easily navigate among your requested reports once they're ready.

If you're requesting a “Favourite Report”, the name of the preset report will be applied to it – but can be edited later on.

As soon as the report is ready, you will be notified via email.

The email will contain an attached XLSX file, in case you want to view the report straight away. The email will also contain a link to the detailed page of the requested report in the Affilka interface where you can download the report via browser.

The available download options for the report include the following formats:

- Zipped CSV – available only for the activities report. The archive will consist of 2 files: report rows and report totals;
- XLSX – available for the activities report (one file divided into 2 tabs with report rows and report totals) and cohort analysis (one file).
