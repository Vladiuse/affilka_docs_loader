You can reach this page via the** /casino/theme_configurator** link.

Here you can customise the colours of the affiliate and operator interface. **Please, note! **The colours you select and save here will apply to ALL USERS on your affiliate program level. These are not your personal settings, but your affiliate program settings.The changes will also apply to the Login/Registration/Reset password forms.

The colour settings are divided into several categories:

- **Font and Background**: here you can set the colours for the fonts and backgrounds used across the entire app.
- **Navigator:**here you can set the colours used in the left-side navigation menu.
- **Semantic emphasis:**represents all buttons (e.g. “Create”, “Add”, “Accept”, “Cancel”, etc) and statuses (“Success”, “Pending”, “Cancelled”, etc) used across the app.
- **Quick charts:**regulates the colours of the current/previous periods within the line charts.
- **Other:**miscellaneous data controls: links, active tabs, various button and filter boundaries as well as rows in various tables.

To save the changes, press “Save”.

To revert to the default interface settings, press “Reset to default”.

To restore the previously saved interface theme version, press “Reset to last saved”.

To view the interface changes in action, you can press on the floating window button in the top right corner of the Interface Window.

You will be automatically redirected to the operator interface dashboard and you can navigate across the app while changing the colours in the interface window which will be floating on top of all the other affiliate program pages. You can also drag the interface window and reposition it from the bottom right corner of the screen to any other place for your convenience.
