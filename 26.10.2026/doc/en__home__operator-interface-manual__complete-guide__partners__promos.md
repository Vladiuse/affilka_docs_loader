In this tab (**/casino/promos**) you will find all promos created by your partners. You can filter and find promos by:

- **Promo**- **IDs**: the filter supports multiple values. You can type several IDs here separated by a comma, “Space” or “Enter” key.. The filter will find all promos with the indicated IDs.
- **Promo**- **codes**: the filter supports multiple values. You can type several promo codes here separated by a comma, “Space” or “Enter” key. The filter will find all promos with the indicated codes.
- **Campaign**- **IDs**: the filter supports multiple values. You can type several IDs here separated by a comma, “Space” or “Enter” key. The filter will find all promos created within the indicated Campaign IDs.
- **Campaign name:**the filter supports partial search. You can type some campaign name partially and press “Filter”, and you will see all promos associated with the campaign name you’ve just typed.
- **Partner IDs:**the filter supports multiple values. You can type several IDs here separated by a comma, “Space” or “Enter” key. The filter will find all promos belonging to the indicated Partner IDs.
- **Partner emails:**the filter supports multiple values. The emails must be typed in full. You can type several emails here separated by a comma, “Space” or “Enter” key. The filter will find all promos associated with the indicated partner emails.
- **Traffic sources**- **:**the filter supports multiple values and autosuggest feature. Start typing “Traffic source” type and it will appear in the dropdown selector. You can choose several traffic sources here and the filter will find promos with any indicated traffic source.
- **Brands:**the filter supports multiple values and autosuggest feature. Start typing the name of the brand and it will appear in the dropdown selector. You can choose several brands and the filter will find promos in any of the indicated brands.
- **Commission IDs**: the filter supports multiple values. You can type several IDs here separated by a comma, “Space” or “Enter” key. The filter will find all promos created with the indicated Commission IDs.
- **Balancer domains:**the filter supports multiple values with autosuggest (id-URL). You can indicate the balancer domain and find which promos use the specific balancer domain.
- **Subaffiliate**(All/Yes/No): finds those promos that are targeting either sub-affiliates or players. The Subaffiliate promos are governed by subaffiliate commission plans. The destination landing page for users attracted via Subaffiliate referral links is generally the main affiliate program website.
- **Landing IDs:**the filter supports multiple values separated by a comma, “Space” or “Enter” key. You can indicate unique IDs and find promos in which specified landings are used.
- **Landing URL:**the filter allows to find promos that redirect traffic to a specific Landing URL. Partial match is supported.
- **Created at:**the filter allows to indicate date ranges (from…to) when the promos were created.
- **Players count:**the filter allows to find promos by a number of registered players (from…up to a specific number of players).
- **Blocked**: True/False. Use it to filter and find promos which were blocked or which are active.

You can export the table in CSV format and open the full screen version of the promos table.

You can view a detailed promo page by clicking on the Promo ID in the promos table.

This page contains the following information about the Promo:

- **Promo**- **ID**– a unique identifier of the Promo.
- **Promo**- **Code**– a unique Promo Code which is an integral part of the affiliate referral link.
- **Promo**- **Name**– the title of the Promo assigned to it either automatically by the system or by a partner at promo editing.
- **Subaffiliate**– depending on a promo type, you can see checkmark or cross graphic.
- **Traffic source**– the traffic source that an affiliate indicated for their referral link. Traffic sources refer to the various channels or methods that guide visitors to a website. These include SEO, social media, email marketing, paid advertising, etc.
- **Created**- **at**- **date**– the date when the Promo was created.
- **Campaign**– the title of the Campaign within which the Promo is created.
- **Partner**– the partner who owns the Promo.
- **Brand**– the brand on which the Promo was created.
- **Commission**– the commission plan attached to this Promo.
- **Landing URL**– landing URL to which the referral link redirects traffic.
- **Players**- **count**– the number of players referred to the iGaming brand via this Promo.
- **Blocked**– the status of the Promo (either blocked or active).
- **Visit cookie lifespan (days)**– count of days of cookie lifetime.

You can block the promo code directly from the Operator Interface. As soon as you block the link, redirects and visits via this link to your iGaming website will no longer be possible. Players will not get redirected to your iGaming brand and there will be no registrations associated with this link.

**To block or unblock the promo**, simply click on the “Block” or “Unblock” button in the top right corner of the detailed Promo page. The link can be unblocked at any time and the flow of customers to your brand via this link will renew. 

You can set an Individual Cookie Lifespan for each promo. Since the default cookie lifespan is set at 30 days for the affiliate program and this means that if the same user clicks 20 times on a referral link within 30 days, in this case 1 click will be counted as unique one, 19 as non-unique.

**To set or change the lifetime of cookie**, click “Edit”, then add the required count of the days and click “Submit”.

**PLEASE, NOTE! **You can use this option not only at the promo level, but also at the brand level, and then the following rule applies: **The individual setting of a more granular level always overrides the setting of a higher level: promo setting overrides brand setting, and brand setting overrides the default affiliate program setting. **


You can indicate the traffic source that the affiliate will be using for a specific referral link by clicking on the “Edit” button for a specific promo.

If an affiliate already indicated something here, you can edit this information. Affiliates cannot edit the “Traffic source” that they indicated – this option is reserved for Operators only.

You can use this information to segment and analyze your affiliates based on their traffic sources. You can also send the information on traffic sources to your brands' landing pages when a player clicks on the tracking link. Contact your account manager at Affilka to get this feature enabled for your brand.

Traffic source field can be made mandatory on the affiliate program level. To make this field mandatory at promo creation, go to All settings>System Management, and enable the “Checkbox” next to this setting.
