The **Subaffiliates** page provides a dedicated, filterable workspace to view and manage all parent–sub-affiliate relationships across your affiliate system in one place. It streamlines auditing and allows affiliate teams to easily trace referral chains, assigned campaigns, and commission strategies.

**Navigation:** Partners → Subaffiliates (located at the bottom of the Partners  block). **URL Path:** /casino/partner_connections

The interactive table includes a full-screen mode toggle and defaults to 20 items per page (selectable options: 20 / 50 / 100).

- **Parent Affiliate:**Displays Company name (ID: :id) with a direct link to the parent affiliate's detail page.
- **Subaffiliate:**Displays Company name (ID: :id) with a link to the sub-affiliate's detail page.
- **Level:**The relative subaffiliate tier depth in relation to the parent affiliate.
- **Campaign:**Displays Campaign name (ID: :id) with a link to the campaign detail page.
- **Promo:**Displays Promo name (ID: :id) with a link to the promo detail page.
- **Assigned at:**Date stamp showing when the sub-affiliate was linked to the parent.
- **Strategy:**The specific commission strategy associated with the connection.

Filters can be pinned or unpinned to customize your workspace view (all filters are pinned by default):

- **Parent Affiliate IDs**— filter by parent affiliate identification numbers.
- **Subaffiliate IDs**— filter by sub-affiliate identification numbers.
- **Subaffiliate Level**— multi-input with autosuggest listing all sub-affiliate levels active in Affilka.
- **Campaign IDs**— filter by specific campaign IDs.
- **Promo IDs & Promo codes**— search by specific promo IDs or promo code strings.
- **Strategies**— multi-input with autosuggest listing all subaffiliate commission strategies configured in Affilka.
- **Subaffiliate assigned at**— date range picker to filter by assignment date.

- **Export Content:**Downloads a CSV file containing all table data, maintaining the exact column order shown on the page.
