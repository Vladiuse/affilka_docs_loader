You can reach this page via the **/casino/postbacks_log** link.

To learn more about postbacks, what they are and how they can be configured, read here.

As an Operator, you can find out whether the postback was triggered or not. Here you can find the required postback by:

- **Postback**- **actions**– the action type which triggered the postback (e.g. registration, first deposit, etc – you can choose several, events, the filter finds postbacksfor any of the indicated events);
- **Response code**– the- __http status code__of the affiliate tracker response;
- **Postback URL**– the affiliate tracker URL to which the postback is sent. The filter supportspartial-match mode;
- **Player**- **IDs**– will find postbacks triggered for any of the indicated player IDs. The filter supports multiple search and exact match mode;
- **Promo IDs and Promo codes**– will find postbacks triggered for any of the indicated promos. The filter supports multiple search and exact match mode;
- **Campaign IDs**– will find postbacks triggered for any of the indicated campaign IDs. The filter supports multiple search and exact match mode;
- **Campaign**- **name**– will find postbacks triggered for the indicated campaign name. The filter supports partial match mode;
- **Partner name**(partial match),- **email**(partial match) and- **ID**(multiple search, exact match, finds postbacks triggered for any of the indicated partners),
- **Time it was sent**(from…to date range);

You can export the table in CSV format and open the full screen version of the postbacks log table.

With this sorting, you can select your mostly used filters on the Postbacks log and thereby optimize the space of the page you are viewing.

In order to set this, please do the following:

- Point a cursor on one of the filters and you'll see the PIN icon in front of the filter name.
- Click on the active PIN icon.
- After that filter will be sorted down to the “Show more” section.
- To pin the filter back you will need to click on the non - active PIN icon of the filter.

** NOTE!** Settings are applied for each account individually.
