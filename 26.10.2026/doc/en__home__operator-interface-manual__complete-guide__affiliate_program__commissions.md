The page can be reached via the** /casino/commissions** link.

Here you can view and manage the commission plans available in your affiliate program. In order to perform any actions with commissions, you need to have either SuperOperator access or a role with "Commissions Process" permission enabled.

The list of commissions is divided into 4 tabs: All, Published, Draft, and Archived.

On the right of the page you can find two clickable columns:

- **Campaigns Count:**clicking the number in this column opens the Campaigns page, automatically filtered by the selected commission.
- **Partners Count:**clicking the number in this column opens the List of Partners page, automatically filtered by the selected commission.

You can filter the commission plans by:

- **Commission IDs**: finds commissions by their IDs. Supports multiple values.
- **Title**(dropdown selector, supports multiple values and an autosuggest feature): finds commissions by the title.
- **Brand**(dropdown selector, supports multiple values and an autosuggest feature): finds all commission plans created for this brand(s);
- **Strategies**(dropdown selector, supports multiple values and an autosuggest feature): finds all commission plans with any of the indicated strategies.
- **Commission currency**(single input + autosuggest) displays base currencies available across your casino brands (All is selected by default). Filtering shows commissions that contain at least one- **Rule Group**in the specified currency.
- **Conditions**(autosuggest + range From / To) suggests only the conditions currently used in your affiliate system. You can filter by condition type alone, or specify a precise numeric range. Specify currency for monetary range.
- **Qualifiers**(autosuggest + range From / To) suggests only the qualifiers currently used. Allows filtering by type or by a specific numeric range.Specify currency for monetary range.
- **Rewards**(autosuggest + range From / To) suggests only the rewards currently used. Allows filtering by type or by a specific numeric range.
- **Modifiers**(single input + autosuggest) suggests modifiers used in your system. Modifiers with sub-options (like- **Activity from**) are split into separate selectable options (e.g.,- *Activity from last bill*,- *Activity from day*, etc.).
- **Forgive debts**(All/Yes/No): Filters commissions based on their "Forgive Debts" status. Select “Yes” to view commissions with the setting enabled, “No” for those with it disabled, or “All” to view both.
- **Casino admin fee, % (from/to)**finds commissions in the specified percentage range of the casino admin fee.
- **Sportsbook admin fee, % (from/to)**finds commissions in the specified percentage range of the sportsbook admin fee.
- **Poker admin fee, % (from/to)**finds commissions in the specified percentage range of the poker admin fee.
- **Commission tags**(dropdown selector, supports multiple values and an autosuggest feature): finds commissions by assigned tags.
- **Schedule**- **plans**(dropdown selector, supports multiple values): finds all commission plans that are paid out either daily, weekly, monthly or on specific dates.
- **Default**(Yes/No): finds either default or non-default commission plans.
- **Subaffiliate**(All/Yes/No): finds those commissions that are either available to subaffiliates or are available only to players.
- **Balancer domain URLs**(dropdown selector, supports multiple values and an autosuggest feature): finds the commissions at which the selected balancer - domain is active.
- **Published at (from/to dates):**finds commissions published in the specified date range.

Batch actions allow you to apply specific actions to commissions in a batch. So you can:

- publish commissions
- archive commissions
- add tags to commissions
- remove tags from commissions

**NOTE! **Batch actions are applied page by page basis. So if you are on page 1 of 10 and you want to apply the action to all 10 pages, you will need to repeat the same action for each page.

After choosing add/remove actions, you will see a pop-up window displaying the tags section from which you can choose tags that you want to assign or unassign from commissions.

to create a commission, press “New”. A complete commissions constructor guide is available here.

All commissions are created in "Draft" state. To make them available to affiliates, make sure you publish them.

**Please, note!**** You can change the commission state to “Default” only after it’s published and after you’ve indicated the brand and the balancer-domain it is attached to.**

to edit a commission, press “Edit” next to its name.

If a commission is in “Draft” state – you can edit it in full.

If a commission is published but is not used in any campaigns yet and there are no players who followed the link attached to this commission – you can edit it in full.

However, if a commission is already used by affiliates and some players were referred on this commission plan, you cannot edit its configuration. You can only edit its Title.

to archive a commission, press “Archive” on a detailed commission page. To get to a detailed commission page, simply press on its name.

What happens after the commission is archived?

- Affiliates cannot create new campaigns with this commission
- If there is no commission of the same strategy in default state or assigned to partners individually, it will keep working for old campaigns it was already used in.

To make a commission default, you first have to publish it. To change the commission state from/to default, you need to press on the commission name and enter commission view mode. Here you can tick off the checkbox indicating its default status.**Please, note! ****Only 1 commission of the same strategy can be default for 1 brand.** *E.g. if you have 10 revshare commissions and 10 cpa commissions on Brand A, only 1 revshare and only 1 cpa commissions can be default for this brand. *

 

If you want to change the current default commission to a new one:

- Create a new commission with the same strategy as the current default commission, check **Enable**, and publish the commission.
- Uncheck **Default**for the old default commission (with the same strategy) and set**Default**for the new commission**one day before**the new default commission should take effect.

**Please note!**If your invoices are issued on the **first day of the following month**, make this change on the **last day of the current month**.

An invoice based on the old default commission will be issued **the day after** the Default checkbox is removed from the old commission and the new default commission is assigned.

The new default commission will be applied to **existing partners’ current campaigns** and will also become available for **creating new campaigns** starting from the next day.

To choose the brands for which this commission will be active, you need to press on the commission name and enter commission view mode. Here you can tick off the checkboxes next to brand names.

A balancer domain is used for generating all referral links within your affiliate program. They are different for different brands and 1 brand can have more than one balancer domain.

Balancer domain is indicated in commission settings. To choose the balancer domain which will be attached to a specific commission, press on the commission name and enter commission view mode. Here you can tick off the checkboxes next to brand names and here you can choose balancer domain through which referral links will be created for this commission.

Having several balancer domains for 1 casino allows you to disperse your traffic. *E.g. you can set one balancer domain for web traffic, another for email traffic and another for mobile apps traffic. In such a way, if one balancer domain gets blocked, others will continue to be fully functional. So there will be no major interruptions to your traffic flow, just to a small fraction of it.*

**Please, note! ****Only Affilka team can add various balancer domains to your brand settings. So if you want to add new domains to your settings, please, contact us.**
